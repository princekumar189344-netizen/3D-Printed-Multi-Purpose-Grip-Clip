# 3D-Printed-Multi-Purpose-Grip-Clip

## About the project 

This is the 3D model of the small grip clip. I used a real black clip as the reference for making the model. 

I made the model step by step in the CAD software. I am first make the men body and after I work on the grip section, middle section, hinge area and finally made some size and design changes. 

----

## Project goal

The main goal of the project was to learn basic 3D modelling and make a CAD model. 

----

## What I learned 

- Computer
- CAD software
- real grip clip from reference
- STL file
- STEP file
- basic measuring and checking.

----

# 3D modelling

first I open the CAD software in the computer and open a new file and started a new model.

I make the basic body of the grip clip. I added the main shape, center opening, and a hole. I kept the model simple at this stage.

## Step 2 - grip and middle section 

In step 2, I continue working on the model.

I changed the length and with of the body. I also worked on the raised grip section and the middle part of the clip where the arms connect. 

I made a small hole in the one part and the small part on the another arm so they can fit together.

## Step 3 - hinge area 

In step 3 I work on the hinge area.

I made the hinge sections on both sides of the clip and aligned them. I also made the long thin hinge holes show the inch pin pass through.

I check the model from the different directions to make sure the hinge parts were in the correct position.
